This repository contains my **Data Structures and Algorithms (DSA) coursework**, implemented in **Java**.

The coursework focuses on applying algorithmic problem-solving techniques to different real-world scenarios, including **energy management, logistics, trading, tourism, weather data, and computational geometry**.

## 📚 Coursework Questions

### 1️⃣ Maximum Points on a Line

**File:** `Question1a_MaxPointsOnLine.java`

An algorithmic problem focused on finding the maximum number of points that lie on the same straight line.

**Concepts:**

* Computational geometry
* Hash maps
* Coordinate calculations
* Algorithm optimization

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/salifa11/dsa_coursework_salifa.git
```

### 2. Navigate into the project

```bash
cd dsa_coursework_salifa
```

### 3. Compile a Java program

For example:

```bash
javac Question1a_MaxPointsOnLine.java
```

### 4. Run the program

```bash
java Question1a_MaxPointsOnLine
```

You can repeat the same process for the other `.java` files.
